# 18.6: Global Search Wiring — Modal Query Debounced ke API

**Story ID:** 18.6
**Epic:** 18 — Client API Wiring: Honest Data Everywhere (Course Correction 5)

status: ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

## Story

As a **pengguna WORKSTATION**,
I want **Cmd+K mencari lintas tiket/work item/KB/insiden di seluruh data server (Epic 15.2)**,
so that **hasil pencarian mencakup seluruh data organisasi yang nyata — bukan hanya state lokal yang kebetulan termuat**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `GlobalSearchModal` mem-query `GET /api/v1/search?q=` (debounce ±250–300ms, min 2 karakter sesuai validasi server) dengan React Query `enabled` hanya saat modal terbuka + query valid + `!DEMO_MODE && isAuth`.
2. Hasil dinormalisasi ke item navigasi modal eksisting (tab tujuan + label tipe); klik hasil tetap menavigasi via callback `onNavigate` yang ada.
3. Boot real: hasil mencakup domain server (tickets/work items/KB/incidents); mode demo: perilaku lama (props lokal) tetap dipakai — gating `DEMO_MODE` memilih sumber.
4. State loading/kosong/error di modal jujur dan informatif (bukan area kosong tanpa pesan).
5. Endpoint server TIDAK diubah; props lama modal tidak dihapus (masih dipakai mode demo) — hanya jalur sumber data yang ditambah.
6. `npm run lint` (tsc strict) dan seluruh test tetap hijau; test baru untuk normalisasi hasil & gating.

## Dev Notes

- **Endpoint:** `GET /api/v1/search?q=` — `searchService.search(q)` → `data: { query, results, total }`; server menolak `q` < 2 karakter (VALIDATION_FAILED) — client juga menjaga minimal 2 karakter.
- **Modal eksisting** menerima props array (workItems, tickets, deployments, incidents, commits) — pertahankan untuk mode demo; jalur real mengganti SUMBER hasil, bukan struktur UI.
- **Story ini TIDAK menyentuh blok sumber data `App.tsx`** — satu-satunya story 18.x yang bisa jalan paralel; tetap disequentialsesuai wave plan demi kesederhanaan.
- **Terkait:** 15.2 (server search) · 18.5 (sebelumnya — penutup Epic 18).
