# 14.1: Sprint & Milestone Schema, Assignment, CRUD API

**Story ID:** 14.1 · **Epic:** 14 · **Slug:** sprint-milestone-management
status: done

## Story

As a **Tech Lead**, I want **sprints and milestones that work items can be assigned to**, so that **delivery is organized in time-boxed iterations with clear targets**.

## Acceptance Criteria

<!-- LOCKED -->
1. Tabel `sprints` (projectId FK, name, goal, startDate, endDate, status PLANNED/ACTIVE/CLOSED) dan `milestones` (projectId FK, name, targetDate, status OPEN/CLOSED, description) via migrasi Drizzle.
2. Kolom `sprintId` dan `milestoneId` (nullable FK) pada `work_items`.
3. CRUD API `POST/GET/PATCH /api/v1/sprints` & `/api/v1/milestones` (RBAC: buat/ubah PERM_WORK_ITEM_CREATE/UPDATE; lihat PERM_VIEW_DASHBOARD).
4. Assignment: `PATCH /api/v1/work-items/:id` menerima `sprintId`/`milestoneId` (null = unassign); id tak valid → 400.
5. Aturan bisnis: hanya SATU sprint ACTIVE per project — aktivasi sprint kedua ditolak 400; sprint hanya bisa CLOSED dari ACTIVE.
