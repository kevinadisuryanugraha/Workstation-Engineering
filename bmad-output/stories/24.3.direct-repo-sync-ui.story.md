# 24.3: Direct Repository Sync UI — URL Input, Sync Button & Real Feed Hydration

**Story ID:** 24.3
**Epic:** 24 — Full Real CRUD Persistence & Direct Repository Sync (Course Correction 9)
**Slug:** direct-repo-sync-ui
status: ready-for-dev

## Story

As a **Developer / Tech Lead**,
I want **dapat memasukkan link repositori GitHub/GitLab (misal `https://github.com/kevinadisuryanugraha/Workstation-Engineering`) di UI Git Intelligence dan menekan tombol 'Sinkronkan Sekarang'**,
so that **riwayat commit dan pull request nyata langsung tampil di layar dan evidence kode terhubung secara instan**.

## Acceptance Criteria

<!-- LOCKED -->

1. Form Sinkronisasi di `GitIntelligenceView.tsx`:
   - Input **"Link Repositori Git"** (menerima URL lengkap seperti `https://github.com/owner/repo` atau format `owner/repo`).
   - Pilihan Provider (otomatis terdeteksi dari URL bila menyertakan `gitlab.com` / `github.com` / `bitbucket.org`, atau dipilih manual).
   - Input opsional: Personal Access Token (untuk repositori privat).
   - Tombol **"Sinkronkan Data Sekarang"** (dengan animasi loading / progress saat proses sync berjalan).
2. Hook `useSyncRepository` di `src/hooks/api/useGitRepositories.ts`:
   - Mengirim request ke `POST /api/v1/git/sync-url` atau `POST /api/v1/git/repositories/:id/sync`.
   - Menginvalidasi cache React Query `['gitCommits']`, `['gitPullRequests']`, `['gitRepositories']` saat sukses.
3. Notifikasi & Feedback UI:
   - Menampilkan banner ringkasan hasil sync: misal *"Berhasil menarik 25 commit, 3 PR, dan menautkan 4 evidence kode"*.
   - Feed Commits dan PRs di UI langsung ter-refresh dan menampilkan commit terbaru.
4. Button "Sync" per repositori terdaftar pada tab **"Repos"** untuk sinkronisasi ulang berkala.
5. `npm run lint` + seluruh test hijau; test baru di `tests/git-sync-ui.test.ts` memverifikasi deteksi provider dari URL, trigger mutasi sync, dan invalidasi query.

## Tasks / Subtasks

- [ ] Task 1: Buat hook `useSyncRepository` di `src/hooks/api/useGitRepositories.ts`
- [ ] Task 2: Tambahkan UI form input Link Repo & tombol Sync di `GitIntelligenceView.tsx`
- [ ] Task 3: Hubungkan tombol sync per-item di tab Repos
- [ ] Task 4: Tulis test `tests/git-sync-ui.test.ts`
- [ ] Task 5: Verifikasi lint + test suite + build
