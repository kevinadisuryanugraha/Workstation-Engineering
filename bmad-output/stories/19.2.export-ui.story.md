# 19.2: Export UI — Tombol Unduh PDF/Excel di Panel Laporan

**Story ID:** 19.2
**Epic:** 19 — Report Export: PDF & Excel (Course Correction 6)
**Slug:** export-ui
status: ready-for-dev

## Story

As a **manajer/tech lead**,
I want **tombol "Export PDF" dan "Export Excel" pada laporan yang sedang dilihat**,
so that **saya bisa mengunduh laporan tanpa memanggil API manual**.

## Acceptance Criteria

<!-- LOCKED -->

1. Panel laporan arsip (ReportView / panel generated reports di App) menampilkan tombol Export PDF & Export Excel untuk arsip yang sedang aktif/terpilih.
2. Klik tombol → fetch endpoint 19.1 dengan kredensial (apiClient), respons diubah menjadi unduhan file (blob + `URL.createObjectURL`), nama file dari header `Content-Disposition` bila ada, fallback nama generik `laporan-{type}-{tanggal}.pdf|xlsx`.
3. State jujur: loading (tombol disabled + label "Menyiapkan…"), error (pesan inline/notif jujur), sukses (unduhan terpicu). Tidak ada area mati tanpa umpan balik.
4. Gating permission: tombol disembunyikan untuk role tanpa `PERM_AUDIT_LOGS_VIEW` (konsisten dengan akses panel laporan — panel itu sendiri sudah tergating).
5. Mode demo: tombol tetap tampil namun memicu pesan jujur "Ekspor hanya tersedia dengan data server nyata" — TIDAK membuat file palsu.
6. `npm run lint` + seluruh test hijau; test baru: pemilihan nama file, blob download trigger (mock URL API), gating demo & permission.

## Dev Notes

- **apiClient** (`src/lib/apiClient.ts`) menangani auth header — gunakan `responseType: 'blob'` atau fetch manual lalu `res.blob()`.

- Tailwind 4, ikon/label konsisten dengan tombol eksisting panel laporan.
- Mode demo dikenali via `DEMO_MODE` flag eksisting (17.2).
