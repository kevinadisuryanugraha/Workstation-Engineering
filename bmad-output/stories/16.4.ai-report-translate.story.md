# 16.4: AI Report Translation EN↔ID via Gemini (graceful 503)

**Story ID:** 16.4 · **Epic:** 16 · **Slug:** ai-report-translate
status: done

## Story

As a **Manager / international stakeholder**, I want **archived management reports translated between Indonesian and English by AI**, so that **reports are readable across languages without manual rework**.

## Acceptance Criteria

<!-- LOCKED -->
1. `POST /api/v1/reports/:id/translate` body `{targetLanguage: "en"|"id"}` (PERM_AI_TRANSLATE): menerjemahkan `contentMarkdown` arsip via Gemini; hasil disimpan di kolom baru `translationMarkdown` + `translationLanguage`.
2. Laporan sumber TIDAK PERNAH tertimpa — terjemahan disimpan terpisah.
3. Tanpa `GEMINI_API_KEY` → HTTP 503 `AI_NOT_CONFIGURED` dengan pesan jelas (NFR-006: tanpa key = tanpa panggilan network).
4. `GET /api/v1/reports/history/:id` mengembalikan `translationMarkdown` + `translationLanguage` bila sudah diterjemahkan.
5. Terjemahan ulang (target berbeda) menimpa kolom terjemahan — sumber tetap utuh.

## Tasks / Subtasks

- [ ] Endpoint + guard key (AC #3, #4)

- Format respons Gemini dibungkus try/catch → 502 AI_TRANSLATION_FAILED bila output tidak valid.
