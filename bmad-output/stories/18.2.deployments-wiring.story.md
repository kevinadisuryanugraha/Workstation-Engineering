## Story

As a **pengguna WORKSTATION di boot produksi**,
I want **tab Production Deployments menampilkan rilis nyata dari API**,
so that **riwayat deployment yang saya lihat adalah fakta operasional — bukan rilis fiktif seperti "v2.8.1" yang dulu jadi keluhan owner**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Client memakai React Query (`GET /api/v1/deployments` — endpoint eksisting) dengan gating `!DEMO_MODE && isAuth`, queryKey konsisten (`deployments`).
2. Boot real: `DeploymentsView` menampilkan deployment nyata; honest-empty notice (17.3) hilang saat data mengalir. Mode demo: seed mock + perilaku lama utuh.
3. Mapper DTO→UI `Deployment` = pure function testable; field tampilan tanpa padanan API (mis. gates, duration) memakai placeholder jujur/netral — bukan nilai fabricated.
4. Endpoint server TIDAK diubah sama sekali (story ini murni client).
5. `npm run lint` (tsc strict) dan seluruh test tetap hijau; test baru untuk mapper + hydration contract.
