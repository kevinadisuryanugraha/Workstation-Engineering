# 22.2: Debt Registry — Tab Technical Debt Data Nyata

**Story ID:** 22.2
**Epic:** 22 — Technical Debt Registry (Course Correction 7 / DEF-006, Master PRD §11.4)
**Slug:** debt-registry-ui
status: ready-for-dev

## Story

As a **tech lead**,
I want **tab "Technical Debt" di AI Intelligence View menampilkan daftar debt nyata dari API registry (aging, origin, impact, owner, target milestone, evidence)**,
so that **saya bisa memantau hutang teknis secara jujur dan terurut — bukan melihat tab yang selalu kosong di boot real**.

## Acceptance Criteria

<!-- LOCKED -->

1. Hook BARU `useDebtRegistry` di `src/hooks/api/useAiIntel.ts` (file hook AI eksisting): fetch `GET /api/v1/work-items/debts` via React Query, gating `enabled` mengikuti pola 18.5 (non-demo, session ada, permission `PERM_WORK_ITEM_VIEW`).
2. `App.tsx`: state `technicalDebts` kini ter-hydrate dari API nyata pada boot non-demo melalui mapper kontrak (`DebtRegistryItem` → bentuk UI) — mengikuti pola hydration findings/recommendations 18.5; mode demo (`VITE_DEMO_MODE=1`) tetap memakai seed mock eksisting.
3. Tab `techdebt` di `src/components/AIIntelligenceView.tsx` menampilkan: (a) ringkasan agregat dari `meta.summary` (total open + distribusi aging bucket FRESH/AGING/STALE/CRITICAL dengan badge warna bertingkat); (b) daftar debt — key, title, origin (badge), impact (HIGH/MEDIUM/LOW), status, owner, target milestone, effort, aging (angka hari + bucket), evidence `debtSourceRef` bila ada; (c) filter status/origin/impact + pencarian teks klien-side; (d) urut default aging terlama dulu.
4. Honest-empty tetap jujur: boot real tanpa data → empty state informatif (pola 17.2) TANPA fallback data palsu; loading & error state tidak pernah crash — tidak ada dereference array kosong/undefined tanpa guard (kontrak hotfix produksi #2–#4).
5. Aksi edit TIDAK diduplikasi: baris debt menyediakan tautan/menuju WorkItemsView (tab workitems) — registry bersifat read-only; perubahan status tetap lewat alur work items eksisting.
6. Navigasi TIDAK bertambah item (menjaga kemenangan CC-4: 14 menu); tab tetap di dalam AI Intelligence View yang sudah di-gate `PERM_AI_SCAN_TRIGGER` — konten tab techdebt diminta dengan permission `PERM_WORK_ITEM_VIEW` (hook hanya enabled bila keduanya relevan bagi role).
7. `npm run lint` + seluruh test hijau; test baru `tests/debt-registry-ui.test.ts`: render baris debt dari fixture DTO (aging bucket & urutan benar), filter & pencarian bekerja, empty state jujur, mode demo tetap mock.
