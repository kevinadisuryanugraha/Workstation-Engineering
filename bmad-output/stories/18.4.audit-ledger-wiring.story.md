## Story

As a **Admin/Tech Lead WORKSTATION**,
I want **tab Audit Event Ledger menampilkan log transaksi sistem append-only yang nyata (dengan correlation ID)**,
so that **jejak audit yang saya periksa adalah log produksi sebenarnya — bukan event demo**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Client memakai React Query ke `GET /api/v1/audit-logs` (paginated `page`/`limit`, permission `PERM_AUDIT_LOGS_VIEW` di sisi server) dengan gating `!DEMO_MODE && isAuth`.
2. Adapter DTO→`EngineeringEvent` (kontrak view eksisting) = pure function testable: waktu, ringkasan aksi, aktor, tipe event; correlation ID ditampilkan apa adanya bila field tersedia.
3. Boot real: `AuditLogView` menampilkan log nyata terbaru (halaman pertama); honest-empty notice hilang saat ada data. Mode demo: seed mock utuh.
4. Endpoint server TIDAK diubah (murni client); pagination pertama cukup untuk story ini — UI filter/pagination penuh dicatat sebagai enhancement lanjutan.
5. `npm run lint` (tsc strict) dan seluruh test tetap hijau; test baru untuk adapter.
