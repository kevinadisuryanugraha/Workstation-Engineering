# 17.2: Demo Data Gating — Default Real API Data, Demo Behind Flag

**Story ID:** 17.2
**Epic:** 17 — UI Clarity & Role-Based Navigation (Course Correction 4)
**Slug:** demo-data-exit-strategy
status: ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **pengguna WORKSTATION di produksi**,
I want **aplikasi yang menampilkan data nyata dari API secara default, dengan data demo hanya aktif lewat flag eksplisit dan selalu berlabel "demo"**,
so that **layar terasa tenang dan jujur — kepadatan semu dari mock data (badge commit palsu, node "2 Live", rilis v2.8.1 fiktif) hilang dari pengalaman harian**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Default boot aplikasi (tanpa flag) TIDAK menampilkan satu pun data dari `src/mockData.ts` pada view yang sudah memiliki sumber data API nyata via React Query (`src/hooks/api/*` — work items, tickets, incidents, sprints, server metrics, reports).
2. Mode demo hanya aktif ketika `VITE_DEMO_MODE=1` (atau setara via flag build); dalam mode demo, banner/label demo yang jelas tampil (melanjutkan prinsip SEC-05 "honestly labeled demo data").
3. Ketika mode demo OFF dan API mengembalikan data kosong, view menampilkan empty state yang jujur dan informatif (mis. "Belum ada work item — buat yang pertama") — BUKAN area kosong, BUKAN data palsu.
4. View yang hingga kini HANYA memiliki sumber mock (tanpa endpoint nyata) tidak diubah perilakunya oleh story ini — mereka dicatat dalam Dev Agent Record sebagai daftar temuan untuk keputusan lanjutan (course correction berikutnya), tanpa menghapus datanya di story ini.
5. `metadata.json` (sisa applet AI Studio) tidak disentuh story ini; hanya jalur data runtime frontend yang berubah.
6. `npm run lint` (tsc strict) dan seluruh test eksisting tetap hijau.

## Testing

- Unit test baru `tests/demo-mode.test.ts` (vitest):
  1. Flag OFF → konsumsi data view beralih ke hook API; tidak ada import runtime mock yang tereksekusi.
  2. Flag ON → data mock tampil + banner demo aktif.

- Regression: `npx vitest run` hijau semua; `npm run lint` bersih.
