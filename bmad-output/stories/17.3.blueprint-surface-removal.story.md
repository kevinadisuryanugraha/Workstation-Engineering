## Story

As a **pengguna WORKSTATION**,
I want **menu "Blueprint" tidak lagi tampil di aplikasi**,
so that **produk tidak memajang dokumen arsitektur internal yang isinya outdated (mendeskripsikan target Laravel+PG yang tidak pernah diimplementasi — realitas: Express+Drizzle) dan tidak menambah kebisingan navigasi**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Item "Blueprint" dihapus dari registry navigasi (`src/config/navigation.ts`) dan view `BlueprintView.tsx` tidak lagi dirender/di-import oleh `App.tsx`.
2. Konten `src/blueprintData.ts` (661+ brs) TIDAK dihapus begitu saja — diekspor menjadi dokumen arsip `docs/BLUEPRINT-ARCHIVE-2026-09.md` dengan header disclaimer eksplisit: dokumen ini adalah visi awal (2026) yang TIDAK diimplementasikan; arsitektur aktual adalah React 19 + Express + Drizzle ORM + PostgreSQL 16 (rujukan: `bmad-output/project-documentation.md` §2).
3. Setelah BlueprintView dihapus, bila `src/blueprintData.ts` tidak lagi memiliki konsumen mana pun, file dipindah (bukan hilang) — kontennya hidup di arsip docs/, file TS dihapus dari `src/` dan dihapus pula import-nya.
4. Tidak ada referensi tersisa ke `BlueprintView`/`blueprintData` di `src/` (diverifikasi grep); build produksi sukses tanpa chunk orphan.
5. Role apapun tidak lagi melihat menu Blueprint; jumlah total item nav di registry berkurang 1 (15 → 14) dan grup terdampak tetap valid.
6. `npm run lint` (tsc strict) dan seluruh test eksisting tetap hijau.
