# 1.2: PostgreSQL Schema & Drizzle ORM Setup

**Story ID:** 1.2  
**Epic:** 1 — Core Platform Foundation, Security & Database  
**Slug:** postgres-drizzle-setup  
status: done   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->  

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **Backend Developer / Tech Lead**,  
I want **PostgreSQL 16 persistence configured with Drizzle ORM and migration scripts for core entities (organizations, users, projects, roles)**,  
so that **the system has a permanent, relational system of record, eliminating in-memory data loss (closing Deep Scan DS-09)**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Dependensi `drizzle-orm`, `pg`, `@types/pg`, dan `drizzle-kit` terpasang di project.
2. File konfigurasi `drizzle.config.ts` mendefinisikan koneksi database via environment variable `DATABASE_URL` dengan folder output migrasi `server/db/migrations/`.
3. Skema tabel didefinisikan dengan Drizzle TypeScript:
   - `organizations` (`id`, `name`, `slug`, `created_at`, `updated_at`)
   - `users` (`id`, `email`, `name`, `password_hash`, `role`, `avatar`, `team`, `created_at`, `updated_at`) dengan index pada `email` dan `role`.
   - `projects` (`id`, `key`, `name`, `tagline`, `status`, `created_at`, `updated_at`) dengan unique index pada `key`.
4. Skrip migrasi ter-generate bersih (`npm run db:generate`) dan skrip eksekusi migrasi (`npm run db:migrate`) berhasil dieksekusi terhadap database PostgreSQL target.
5. Modul database client (`server/db/client.ts`) menginisialisasi connection pool dengan penanganan error koneksi yang anggun (*graceful connection error handler*).

## Dev Notes

<!-- LOCKED. Concrete guidance compiled from planning docs with citations. -->

- **ADR-002 Reference:** Drizzle ORM dipilih karena zero runtime overhead dan type-safety murni, menggantikan array in-memory di `server.ts` dan `src/mockData.ts`. [Source: architecture.md#ADR-002]
- **Connection String:** Database URL dibaca dari `process.env.DATABASE_URL` (format: `postgres://user:password@localhost:5432/workstation_dev`). [Source: architecture.md#10-deployment-architecture]
- **Naming Conventions:** Kolom database wajib `snake_case` di level SQL dan `camelCase` di level TypeScript Drizzle definitions. [Source: architecture.md#ADR-008]
- **UUID Strategy:** Gunakan UUIDv7 atau `crypto.randomUUID()` sebagai default value untuk kolom `id`. [Source: architecture.md#5.2]
