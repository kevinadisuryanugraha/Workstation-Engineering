# 7.2: Audit Log Viewer API & Filtering Engine

## Story

As a **Security Admin / Tech Lead**,  
I want **a dedicated API (`GET /api/v1/audit-logs`) to query, filter, and inspect immutable audit trail records with actor, action, date range, and correlation ID filters**,  
so that **governance compliance and forensic inspection can be conducted easily through the UI**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Endpoint `GET /api/v1/audit-logs` mewajibkan permission `PERM_AUDIT_LOGS_VIEW` (hanya Admin, Tech Lead, PM, Manager yang diizinkan; Developer dan Viewer ditolak `HTTP 403 Forbidden`).
2. Mendukung filter query parameters:
   - `actorId` (filter per user yang melakukan aksi)
   - `action` (filter per tipe aksi, misal `AUTH_LOGIN_FAILED`, `DEPLOYMENT_ROLLBACK_EXECUTED`)
   - `targetEntity` (filter per tipe entitas, misal `work_items`, `projects`, `deployments`)
   - `startDate` & `endDate` (filter rentang tanggal ISO 8601)
   - `correlationId` (pencarian jejak transaksi spesifik)
   - `page` & `limit` (pagination standar dengan default 20 item per halaman)
3. Hasil query diurutkan secara kronologis mundur (`created_at DESC`).
4. Detail perubahan pada kolom `details` (JSONB diff) dikembalikan utuh tanpa truncation.
5. Menghubungkan antarmuka frontend `src/components/AuditLogView.tsx` ke endpoint API ini sehingga data riwayat audit tampil secara langsung dari PostgreSQL.
