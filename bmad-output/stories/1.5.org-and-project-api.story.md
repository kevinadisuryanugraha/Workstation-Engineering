# 1.5: Organization & Project Management API

**Story ID:** 1.5  
**Epic:** 1 — Core Platform Foundation, Security & Database  
**Slug:** org-and-project-api  
status: ready-for-dev  

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **Project Manager / Admin**,  
I want **RESTful API endpoints to manage Organizations, Projects, and project memberships with unique project key generation**,  
so that **engineering work items and tickets are properly scoped to specific projects and teams**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Endpoint `GET /api/v1/projects` mengembalikan daftar project di mana user terdaftar sebagai anggota (atau seluruh project jika user adalah Super Admin / Org Admin), mengikuti standard envelope ADR-004.
2. Endpoint `POST /api/v1/projects` (dilindungi `PERM_PROJECT_CREATE` atau role Admin/PM) membuat project baru:
   - Wajib menyertakan `name`, `key` (3-5 karakter alfabet unik huruf besar, misal `WRK`), dan `organizationId`.
   - Menolak pembuatan project dengan key yang sudah terdaftar (mengembalikan HTTP 409 Conflict).
3. Endpoint `GET /api/v1/projects/:id` mengembalikan detail project beserta status (PLANNING, ACTIVE, ON_HOLD, AT_RISK, COMPLETED, ARCHIVED).
4. Endpoint `PUT /api/v1/projects/:id` (dilindungi `PERM_PROJECT_UPDATE`) mengizinkan pembaruan metadata nama, tagline, dan status.
5. Seluruh mutasi entitas project divalidasi inputnya menggunakan skema Zod sebelum mencapai service layer.

## Dev Notes

- **Requirements Citation:** FR-003 Model Entitas Organisasi & Project. [Source: prd.md#FR-003]

## Testing

<!-- LOCKED. STRATEGY ONLY — what to verify and how. -->

- **Approach:** Integration testing dengan mock database repository atau test database.
- **Key scenarios:**
  1. POST `/api/v1/projects` dengan body `{ "name": "Workstation Core", "key": "WRK", "organizationId": "..." }` mengembalikan HTTP 201 dan data project.
  2. POST kedua dengan key `"WRK"` yang sama mengembalikan HTTP 409 Conflict.
  3. GET `/api/v1/projects` mengembalikan array project dalam envelope standar.
