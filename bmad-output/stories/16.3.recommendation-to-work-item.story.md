# 16.3: Recommendation → Work Item Conversion (human approval, idempotent)

**Story ID:** 16.3 · **Epic:** 16 · **Slug:** recommendation-to-work-item
status: done

## Story

As a **Tech Lead**, I want **convert an approved AI recommendation into a work item with evidence links intact**, so that **AI insights enter the delivery pipeline through human judgment**.

## Acceptance Criteria

<!-- LOCKED -->
1. Tabel `ai_recommendations` (snapshotId FK, recRef, title, reason, expectedImpact, effortEstimate, affectedModule, confidence, convertedWorkItemKey nullable UNIQUE) — terisi otomatis saat snapshot disimpan.
2. `GET /api/v1/ai/recommendations?snapshotRef=` (PERM_AI_SCAN_TRIGGER) daftar + status konversi.
3. `POST /api/v1/ai/recommendations/:id/convert` body `{projectId}` (PERM_WORK_ITEM_CREATE — approval manusia): membuat work item type TECH_DEBT, title dari rekomendasi, prioritas P2; menyimpan key hasil ke `convertedWorkItemKey`.
4. Idempoten: rekomendasi yang sudah dikonversi → 409 dengan key work item existing (tidak ada dobel).
5. Work item hasil menyertakan referensi evidence ke scan (dalam deskripsi: scanRef + recRef).

## Tasks / Subtasks
- [ ] Skema + auto-populate saat snapshot disimpan (AC #1)
- [ ] List + convert service (transaksional: insert work item + update key) (AC #3, #4, #5)
- [ ] Tests `tests/recommendation-conversion.test.ts`
