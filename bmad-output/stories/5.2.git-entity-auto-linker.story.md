# 5.2: Git Entity Auto-Linker & Evidence Attachment Engine

**Story ID:** 5.2  
**Epic:** 5 — Git Intelligence & Webhook Engine  
**Slug:** git-entity-auto-linker  
status: ready-for-dev  

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **Developer**,  
I want **the system to automatically parse commit messages and PR titles for entity keys (e.g. `WRK-101`, `TCK-202`) and attach them as verified Git evidence to corresponding tasks and tickets**,  
so that **my work activity is reflected in WORKSTATION automatically without manually pasting commit links**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Skema Drizzle `commits` dan `pull_requests` dibuat di PostgreSQL dengan field: `id`, `repo_id`, `sha` (unik 40 char), `message`, `author_name`, `author_email`, `branch`, `url`, `committed_at`.
2. Saat webhook `push` atau `pull_request` selesai divalidasi oleh Story 5.1:
   - Handler membedah pesan commit dan judul PR menggunakan ekspresi reguler `\b([A-Z]{2,6}-\d+)\b`.
   - Sistem mencocokkan key yang ditemukan dengan tabel `work_items` dan `tickets`.
3. Jika ditemukan kecocokan:
   - Sistem membuat baris di tabel `commits` atau `pull_requests`.
   - Sistem membuat entri di tabel `evidence_links` yang menghubungkan commit/PR ke work item dan/atau tiket terkait.
4. Pada detail tampilan Work Item dan Tiket, bagian "Git Evidence" menampilkan daftar commit SHA, author, timestamp, dan tautan langsung ke GitHub.
5. Pemrosesan parsing regex bersifat *non-blocking* dan tidak mengganggu respons HTTP 202 ke GitHub.
