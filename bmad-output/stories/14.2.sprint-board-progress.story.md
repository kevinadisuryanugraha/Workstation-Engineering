# 14.2: Sprint Board (planned/completed/carry-over) & Panel UI

**Story ID:** 14.2 · **Epic:** 14 · **Slug:** sprint-board-progress
status: done

## Story

As a **Manager**, I want **a sprint board showing planned, completed, and carry-over items with explainable progress**, so that **sprint health is visible without manual counting**.

## Acceptance Criteria

<!-- LOCKED -->
1. `GET /api/v1/sprints/:id/board` (PERM_VIEW_DASHBOARD) mengembalikan: `planned[]`, `completed[]`, `carryOver[]` (work item ringkas: key, title, status), `counts {planned, completed, carryOver}`, `completionPercent` (0-100, dibulatkan).
2. Item berstatus DONE = completed; item assigned ke sprint tapi belum DONE dan sprint sudah CLOSED = carry-over; lainnya = planned.
3. `GET /api/v1/projects/:projectId/sprints` daftar sprint project + ringkasan per sprint.
4. Panel UI di Project 360: pilih sprint → tampilkan progress bar completionPercent + daftar grouped; empty state rapi.
5. Setiap angka dapat di-drill-down (daftar item aslinya disertakan).
