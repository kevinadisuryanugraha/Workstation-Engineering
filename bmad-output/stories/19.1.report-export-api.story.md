# 19.1: Report Export API — PDF & Excel dari Arsip Laporan

**Story ID:** 19.1
**Epic:** 19 — Report Export: PDF & Excel (Course Correction 6)
**Slug:** report-export-api
status: ready-for-dev

## Story

As a **manajer/tech lead**,
I want **mengunduh laporan arsip (generated_reports) sebagai file PDF dan Excel via API**,
so that **laporan manajemen dapat didistribusikan di luar WORKSTATION (lampiran email, cetak, arsip kantor)**.

## Acceptance Criteria

<!-- LOCKED -->

1. `GET /api/v1/reports/history/:id/export.pdf` mengembalikan file PDF (`Content-Type: application/pdf`, `Content-Disposition: attachment; filename=...`) yang berisi metadata laporan + konten markdown yang dirender sebagai teks terformat (heading, paragraf, list sederhana).
2. `GET /api/v1/reports/history/:id/export.xlsx` mengembalikan file Excel valid (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) dengan sheet ringkasan (metadata + KPI dari konten bila dapat diekstrak) dan sheet isi (teks per baris).
3. Kedua endpoint ber-permission `PERM_AUDIT_LOGS_VIEW` (kelas clearance sama dengan viewer laporan) dan audit-logged via `auditService`.
4. Arsip tidak ditemukan → 404 envelope standar; format ekstensi lain → 400 VALIDATION_FAILED.
5. File dihasilkan on-the-fly dari `content_markdown` tersimpan — TIDAK mengubah tabel/arsip (append-only tetap utuh), TIDAK menyimpan file ke disk.
6. `npm run lint` (tsc strict) dan seluruh test hijau; test baru mencakup happy path PDF & XLSX (magic bytes/header), 404, 400, dan permission 403.

## Dev Notes

- **Deps baru:** `pdfkit`, `exceljs` (murni JS, aman untuk bundle esbuild `--packages=external` → runtime `node_modules`). Pastikan tidak menambah native module.
- **Sumber data:** `generatedReportsService.byId(id)` — metadata (`type`, `periodFrom/To`, `generatedAt`) + `contentMarkdown`; jika `translationMarkdown` ada, sertakan sebagai seksi tambahan.
- **PDF:** pdfkit — heading ukuran lebih besar untuk judul, body 11pt, mono untuk tabel/baris KPI; jangan render HTML — markdown diparse ringan (regex baris `#`, `-`, `|`).
- **Excel:** exceljs — sheet "Ringkasan" (metadata + baris KPI yang dikenali dari pola markdown) + sheet "Isi Laporan" (1 baris per baris teks).
- **Envelope:** endpoint file TIDAK memakai JSON envelope sukses (binary stream), tetapi error tetap JSON envelope standar.
- **Terikat pola:** lihat `reports.routes.ts` (safeAsync + requirePermission) dan `audit.service.ts`.

## Testing

- Unit/service test: render PDF → buffer diawali `%PDF`; render XLSX → magic bytes `PK`; error path 404/400/403.
- Regression: full vitest hijau; lint bersih; build sukses.
