# 3.3: Quick Status 1-Click Action & Interactive Evidence Drill-Down UI

**Story ID:** 3.3  
**Epic:** 3 — Developer Experience & "My Work" Workspace  
**Slug:** quick-status-and-evidence-ui  
status: done   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->  

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **Developer**,  
I want **1-click status transitions on my work item cards (e.g. "Start Work", "Submit for Review") and interactive progress bars that drill down to underlying evidence (commits, checklist items, deployment)**,  
so that **updating status takes zero mental friction and progress metrics are fully explainable**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Pada kartu work item di tampilan `OverviewView.tsx` dan `WorkItemsView.tsx`, tombol aksi 1-klik kontekstual ditampilkan:
   - Jika `READY` → tombol "Start" (transisi ke `IN_PROGRESS`).
   - Jika `IN_PROGRESS` → tombol "Submit Review" (transisi ke `IN_REVIEW`).
   - Jika `IN_REVIEW` (dan user adalah Tech Lead/Reviewer) → tombol "Approve" atau "Ready for Test".
2. Transisi status menggunakan mutasi React Query dengan *optimistic update*, sehingga UI merespons seketika tanpa menunggu latency jaringan.
3. Kartu progres deliverable menampilkan bar progres terhitung (misal "75% Complete — 3/4 Criteria Verified"):
   - Mengklik bar progres membuka modal drill-down yang menampilkan daftar kriteria penerimaan, commit SHA bukti terkait, dan status PR.
4. Jika transisi ke `DONE` diblokir oleh kriteria penerimaan yang belum lengkap (dari Story 2.2), modal penolakan ramah ditampilkan menjelaskan kriteria mana yang masih belum tercentang.
5. Mempertahankan gaya visual retro neo-brutalist (borders 2px, hard shadows, grid paper background) konsisten dengan design system eksisting.
