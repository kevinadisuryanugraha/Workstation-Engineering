# 10.2: Bahasa Indonesia Management Summary Generator

**Story ID:** 10.2
**Epic:** 10 — Dual-Language Reporting Engine
**Slug:** id-report-generator
status: ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **Manager**,
I want **the aggregated period data rendered as a readable Bahasa Indonesia management summary (structured text/Markdown) available via API and viewable in the dashboard**,
so that **weekly/monthly reporting to stakeholders is automatic and consistent**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `GET /api/v1/reports/summary/text?from=&to=` (RBAC sama dengan 10.1) mengembalikan laporan Markdown berbahasa Indonesia yang terstruktur: judul + periode, ringkasan Tiket, Work Item, Deployment, Aktivitas Audit, dan kesimpulan otomatis 2-3 kalimat berbasis angka.
2. Narasi berubah sesuai data: bila ada rollback → kalimat peringatan disertakan; bila tiket resolved > open → kalimat positif; angka nol tetap disebut eksplisit ("tidak ada").
3. Tanggal dalam laporan diformat Indonesia (`14 Februari 2026`), bukan format ISO mentah.
4. Generator berupa fungsi **murni** `generateIdReport(summary): string` yang dapat diuji tanpa database — menerima objek agregat dari 10.1.
5. Endpoint teks dan UI: komponen dashboard baru `src/components/ReportView.tsx` menampilkan laporan (render Markdown sederhana / pre-formatted) dengan pemilih periode cepat (7/30 hari).

## Dev Notes

- **Requirements Citation:** Sprint V1.3 — generator ringkasan manajemen otomatis Bahasa Indonesia. [Source: docs/DEEP-SCAN-REPORT-2026-09-18.md §8]
- **Murni & deterministik:** generator rule-based string template — TANPA LLM. Terjemahan otomatis via AI masih PENDING di decision-log; jangan memakai `@google/genai` di story ini. [Source: bmad-output/decision-log.md#AI-PENDING]

- **Data shape:** generator hanya bergantung pada kontrak output 10.1 — jangan query DB di dalam generator. [Source: stories/10.1.report-aggregation-api.story.md]

## Testing

<!-- LOCKED. STRATEGY ONLY — what to verify and how. -->

- **Approach:** Unit test generator murni (mayoritas) + 1 integration test endpoint.
- **Key scenarios:**
  1. Summary dengan rollback > 0 → laporan memuat kalimat peringatan rollback.
  2. Semua nol → laporan tetap valid dan menyebut "tidak ada" untuk tiap bagian.
  3. Rentang 2026-02-09 s.d. 2026-02-16 → laporan memuat "9 Februari 2026" (format ID).
  4. Endpoint menolak role Viewer dengan 403 (konsisten 10.1).
